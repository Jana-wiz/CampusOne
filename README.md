CampusOne

One Campus. One Identity. Infinite Connections.

CampusOne is a campus-exclusive networking platform that enables students to connect, collaborate, discover clubs, find mentors, and access campus opportunities through a unified digital platform.

🚀 Live Demo: https://campus1one.netlify.app

💻 GitHub: https://github.com/Jana-wiz/CampusOne

✨ Key Features

🔐 College Register Number + Email OTP Authentication (Planned)

👥 Student Networking & Connections

💬 Real-time Messaging Interface (UI Prototype)

🎓 Mentor Discovery

🏛 Club Management

📅 Events & Workshops

📚 Academic Resource Sharing

🚀 Opportunities (Hackathons, Internships, Competitions)

📱 Fully Responsive Design
